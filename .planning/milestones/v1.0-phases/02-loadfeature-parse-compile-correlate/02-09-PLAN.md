<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| consumer-supplied path → `loadFeature` | The public entry point; the caller controls the path and runs in their own process |
| public barrel → downstream packages | Everything exported here becomes this library's API surface and its supply-chain obligation |
| `.feature?raw` Vite transform → `parseFeature` | The watch-mode-friendly consumer path, entering through the source form |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-03 | Tampering | `loadFeature(path)` path handling | **accept** | No sanitisation. The caller already controls the path and runs in their own process; no privilege boundary is crossed, so a traversal check would be security theatre. |
| T-02-20 | Elevation of Privilege | the gherkin package acquiring a test-runner or Effect dependency | mitigate | `loadFeature` composes only local modules plus `@cucumber/*`. `packages/gherkin/src` imports no `vitest`, `@effect/vitest`, or `effect`, enforced structurally by the gate script in plan 02-10 and by an acceptance criterion here (`from "effect` count is 0). ADR-EC-015. |
| T-02-21 | Information Disclosure | the public barrel widening the API surface | mitigate | A single barrel, no subpath export. `@cucumber/messages` types are re-exported so consumers are not forced to declare that dependency themselves, but no internal module (`Correlate`, `Validate`, `Parser`, `Source`) is exported. |
| T-02-06 | Tampering | `packageName` / `PackageName` removal breaking the cross-package build | mitigate | Both exports are kept verbatim and asserted by grep, because `packages/vitest/src/index.ts` consumes them and Phase 5 owns that file. |
| T-02-02 | Information Disclosure | collection-error message content in CI logs | accept | Locked full-content policy. A top-level throw surfaces the full `uri:line: reason: guidance` message in the vitest collection error, which is the intended trade for message quality. |
</threat_model>
