| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|

This deliberately overrides the researcher's truncate-by-default recommendation (Assumption A7). The developer chose usefulness over redaction. Do not silently re-add truncation. |

| T-02-07 | Spoofing | error-class identity (`err.name === "Error"`) | mitigate | `this.name` is set explicitly in the constructor and asserted at runtime in `Contracts.test.ts`. Consumers discriminate on `err.reason` / `instanceof`, never on `.name` string matching. |
