Reading the simulated clock from inside a step body:
  `import * as Clock from "effect/Clock"` — then `yield* Clock.currentTimeMillis` inside the
  generator. It yields a value that must be coerced with `Number(...)` before comparison.
  `TestClock.currentTimeMillis` is NOT an Effect in this build and yielding it produces
  `Fiber.runLoop: Not a valid effect: undefined` at run time. This was hit and corrected during
  planning — use `effect/Clock`.

Advancing it:
  `import * as TestClock from "effect/testing/TestClock"` — then `yield* TestClock.adjust("1 hour")`.

Capturing console output:
  `import * as TestConsole from "effect/testing/TestConsole"` — the module `describeFeature.ts`
  already reconstructs `TestEnv` from. Read its own exported surface before writing the console
  half of Task 1; if no per-Scenario-observable accessor exists in `4.0.0-rc.112`, fall back to
  the alternative stated in the action below rather than inventing one.

MEASURED during planning, with `excludeTestServices: true` plus a per-emission
`Effect.provide(testEnv)` in place: three Scenarios under ONE shared Layer each read
`Clock.currentTimeMillis` as 0, including the two that ran AFTER a preceding Scenario had called
`TestClock.adjust("1 hour")` and `TestClock.adjust("2 hours")`. That is the property this plan
asserts; it is already true as of plan 10-02, and this plan is what stops it silently ceasing to be.

MEASURED during planning, for D-03's composition: a Rule `extraLayer` composed as
`Layer.provideMerge(perScenarioLayer)(extraLayer)` and depending on a service the shared tier
provides resolved correctly, with the shared Layer built ONCE and the Rule's Layer built once per
Scenario (measured: sharedBuilds 1, ruleBuilds 2 across two Rule Scenarios).

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Scenario one's `TestClock.adjust` → Scenario two's clock | the boundary ADR-EC-018 exists to re-establish; a leak here makes Scenario execution order semantically load-bearing |
| the `shared` tier → a `Rule`'s per-Scenario `extraLayer` | the shared tier must be READABLE by the Rule's Layer and must not be REBUILT by it — two different properties across one boundary |

No network, no authentication, no persistence, no runtime user input. Risk is test-isolation
correctness and assertion vacuity.
