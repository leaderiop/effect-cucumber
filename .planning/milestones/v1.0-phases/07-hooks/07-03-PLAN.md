<objective>
Extend ADR-EC-016's build gate to cover the hook registrars, so a `HookRegistrar` whose union members
get reordered — or a hook member that leaks onto `ScenarioDsl` — fails a committed assertion instead
of silently passing.

Purpose: `Dsl.ts` note (a) is explicit that a reordered union STILL rejects the bad case, so no
existing test goes red; `effect(missingEffectContext)` just quietly stops covering the new surface.
`test/tsgo-gate/` is the only behavioral proof this repo has for that class of decay, and a hook
registrar with no fixture there has none. 07-PATTERNS.md names this the file class most likely to be
missed.
Output: a satisfied/starved fixture pair, their two single-file tsconfigs, and gate assertions 10
and 11.
</objective>
