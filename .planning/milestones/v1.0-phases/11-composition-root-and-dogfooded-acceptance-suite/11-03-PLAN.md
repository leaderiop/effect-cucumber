## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Gherkin table cells -> `DataTable.hashes()` -> `Schema.decodeUnknown` | Untrusted-shaped string data crosses into typed values; a wrong schema is the failure mode. |
| Rule-scoped `DiscountRegistry` -> Feature-level step bodies | A Rule Layer reachable outside its Rule is INV-EC-005's exact violation. |
| Examples row values -> per-row emitted test | Shared mutable state across rows is the Pitfall 34 regression class. |
