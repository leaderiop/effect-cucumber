## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| a starved `.feature` fixture -> the wrapper's assertion | The wrapper's only input is a deliberately broken artifact; an assertion that is too weak cannot tell one breakage from another. |
| `.feature` tag text repo-wide -> `verify-traceability.sh` checks 4 and 5 | The 22/22 claim is derived entirely from text; a wrong glob or a wrong count constant makes it decorative. |
| a failing step's error -> the `After` hook's finalizer -> the reported cause | A finalizer that replaces rather than merges the cause is the masking BEH-EC-017 forbids. |
