<objective>
Compose `Registry` (05-01), `Dsl` and `Step` (05-02) into the public `describeFeature` entry
point, and replace `packages/vitest/src/index.ts`'s Phase-1 placeholder with a real barrel.

This is where RESEARCH.md Finding 6 lives, and it points the OPPOSITE way from Finding 2:
TypeScript reports overload failures as "the LAST overload gave the following error", so the
**plain-Layer overload must be declared last**. Declared first — which reads more naturally,
because it is the common case — a Layer with an unsatisfied `RIn` is reported as
"missing the properties shared, perScenario", naming the wrong problem entirely, and
`effect(missingLayerContext)` never fires.

Finding 5 also lives here: the spec's published union-argument signature types `shared` as
`Layer.Layer<any, any, never>` and throws its output away, so ADR-EC-006's own motivating
example (`shared: Database.layer`) does not compile. Two overloads fix it; a union cannot.

Purpose: this is the file a test author calls, and the only place `RShared | RScenario` gets
threaded into `FeatureDsl`.
Output: one source module, one unit test, one rewritten barrel, one stale comment retired.
</objective>
