<objective>
Turn two written conventions into mechanical gates. AGENTS.md §3 mandates
submodule namespace imports (`import * as Effect from "effect/Effect"`, never
from the `effect` barrel) and nothing checks it. The `tools/oxlint/effect/`
directory that would check it exists on disk but is **untracked in git** — one
`rm -rf node_modules` away from being lost.

This plan installs oxlint + dprint, adopts Effect's formatting config verbatim
(no semicolons — the locked decision), wires the vendored rules in as
build-breaking errors, and commits `tools/`.

Purpose: Half of Phase 1 success criterion 3 (`oxlint` and `dprint --check` run
clean over the repo); CI wiring lands in plan 01-06.
Output: `pnpm lint` and `pnpm lint-fix`, a formatted repo, and a tracked
`tools/oxlint/effect/`.
</objective>

Create `.oxlintrc.json` merging §5.1's base rule set with §5.1a's plugin wiring:

```jsonc
{
  "$schema": "https://raw.githubusercontent.com/oxc-project/oxc/main/npm/oxlint/configuration_schema.json",
  "plugins": ["typescript", "import", "oxc", "eslint", "unicorn", "vitest"],
  "jsPlugins": [
    { "name": "effect", "specifier": "./tools/oxlint/effect/index.ts" }
  ],
  "categories": { "correctness": "error", "suspicious": "error", "perf": "error" },
  "ignorePatterns": [
    "**/dist",
    "**/node_modules",
    "**/*.md",
    ".planning",
    "packages/vitest/test/tsgo-gate"
  ],
  "rules": {
    "eqeqeq": "error",
    "import/no-cycle": "error",
    "import/no-duplicates": ["error", { "preferInline": true }],
    "typescript/consistent-type-imports": ["error", { "fixStyle": "inline-type-imports" }],
    "typescript/no-import-type-side-effects": "error",
    "typescript/no-unnecessary-type-assertion": "error",
    "typescript/no-unused-vars": ["error", { "argsIgnorePattern": "^_", "varsIgnorePattern": "^_" }],
    "unicorn/prefer-node-protocol": "error",
    "vitest/no-focused-tests": "error",
    "vitest/no-identical-title": "error",
    "effect/no-import-from-barrel-package": ["error", {
      "checkPatterns": [
        "^effect$",
        "^effect/(.+/)?[a-z][a-z0-9]*$",
        "^@effect/[^/]+$",
        "^@effect/[^/]+/(.+/)?[a-z][a-z0-9]*$"
      ],
      "checkRelativeIndexImports": true
    }],
    "effect/no-js-extension-imports": "error",
    "effect/no-opaque-instance-fields": "error",
    "effect/no-bigint-literals": "error"
  }
}
```

The plugin `name` must stay `"effect"` so rule IDs match upstream's. The
tsgo-gate fixture is ignored because it contains deliberately-wrong code that is
the *type checker's* problem, not the linter's.

```jsonc

"lint-fix": "oxlint --fix && dprint fmt"
```
