<objective>
Pin, against the real `@cucumber/gherkin@42.0.1`, every DataTable and DocString shape fact that
the rest of Phase 4 builds on — before any wrapper code exists to be blamed for a failure.

Purpose: `packages/gherkin/test/upstream-pin.test.ts` imports nothing from `../src` on purpose.
When it fails, a dependency changed its semantics; when `DataTable.test.ts` fails, this library
did. Phase 4's accessor and ordering rules rest on four upstream facts that are currently
assumed rather than asserted: that `argumentIndex` is `1`/`2` when a step carries both a DocString
and a DataTable, that it is **absent** when a step carries only one, that a header-only table and
a single-column table both parse cleanly, and that a `PickleTableRow` carries no location.

Output: five new `.feature` fixtures, a Group E section in the fixture corpus README, and a new
`describe` block in `upstream-pin.test.ts`.
</objective>
